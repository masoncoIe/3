# Cole Browser

A minimalist black-themed web proxy browser. No downloads or setup required - just deploy to Vercel.

## Features

- Clean, gothic-inspired design with dark theme
- Built-in proxy for browsing websites
- Search with DuckDuckGo
- Navigation history with back/forward buttons
- Works out of the box - no configuration needed

## Usage

1. Deploy to Vercel using the "Publish" button
2. Enter any URL or search term in the search bar
3. Press Enter or click "Enter" to navigate

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Development

```bash
pnpm install
pnpm dev
```
